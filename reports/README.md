매달 1일 자동 발행되는 한국 선케어(선스크린) 시장 트렌드 리포트 저장소입니다.

## 구조

```
reports/
  suncare/
    YYYY-MM-선케어-리포트.md   ← 매달 1일 자동 업데이트
```

## 리포트 구성 (맥킨지 피라미드 구조)

1. **Executive Summary** — 핵심 변화 3가지 + So What
2. **수출·유통 동향** — 국별 수출 통계, 실리콘투 등 유통 기업 동향
3. **채널별 제품 동향** — 올리브영·무신사·쿠팡·글로우픽·화해 순위
4. **제형 트렌드** — 상승/하락 제형, 신규 등장
5. **성분 트렌드** — UV필터 및 부원료
6. **이머징 시그널** — 신흥 트렌드, 규제, 해외 이슈
7. **OTC 선크림 동향** — FDA 모노그래프, 미국 시장
8. **R&D 제안** — 다음 달 우선 검토 제품 아이디어

## 옵시디언 연동 방법

1. 이 저장소를 옵시디언 볼트 폴더에 클론 또는 Obsidian Git 플러그인으로 연결
2. Auto pull interval 5분 설정
3. 매달 1일 리포트 push 후 자동 동기화
