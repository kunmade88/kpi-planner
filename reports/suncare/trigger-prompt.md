## STEP 0.9. 발행 전 감독관 검토 — 전 섹션 필수 통과

> 리포트 초안 완성 후, 저장·배포 전에 아래 체크리스트를 **순서대로 전부** 수행한다.
> 하나라도 실패하면 해당 내용을 수정 후 재검토한다. 체크 완료 후에만 저장한다.

### [CHECK 1] 수치·건수·순위 출처 전수 확인
리포트 내 모든 숫자(수출액·거부 건수·순위·성장률·시장 규모·SPF 수치·농도 등)에 대해:
- 해당 수치가 이번 STEP 0~0.7 WebSearch에서 직접 확인된 것인가?
- 출처(매체명·날짜)가 Sources 섹션에 명시되어 있는가?
- **하나라도 출처 없으면 → 해당 수치 삭제 또는 [미확인] 표기**

### [CHECK 2] 기업명이 포함된 모든 문장 재검토
리포트에 기업명(코스맥스·코스메카코리아·서울화장품·한국콜마·LG생활건강 등)이 등장하는 모든 문장에 대해:
- 해당 기업의 **정확한 행위·상황·제품** 을 원본 검색 결과에서 직접 확인했는가?
- 기업을 특정 카테고리(예: "MoCRA 미갱신 기업", "규정 위반 기업")로 분류할 때, 해당 분류의 근거가 원본 출처에 명시되어 있는가?
- **출처 없이 기업에 문제·위반·실패를 귀속하는 문장은 즉시 삭제**
- 특히 주의: 거부 건수가 높다 ≠ MoCRA 갱신 미완료. 이 두 가지를 절대 동일 카테고리로 묶지 않는다.

### [CHECK 3] 인과관계·이유·원인 서술 검토
"~때문에", "~로 인해", "~이유로" 등 원인을 서술한 모든 문장에 대해:
- 해당 원인이 WebSearch 원본 출처에서 명시된 것인가?
- 추론·가설로 작성된 원인인가? → **[추론]** 표기 또는 삭제
- 특히 주의: 기업의 거부·위반·실패 원인을 출처 없이 설명하지 않는다.

### [CHECK 4] 법률명·고시명·규정명 정확성 확인
규제·법률·행정예고 관련 공식 명칭에 대해:
- 법률명(예: "SAFE Sunscreen Act", "MoCRA", "EmpCo" 등)이 원본 출처의 공식 명칭과 일치하는가?
- 연도가 포함된 법률명은 특히 WebSearch로 재확인한다.
- 공식 명칭이 확인되지 않으면 "관련 법안" 등 일반 표현으로 대체.

### [CHECK 5] 독점·계약·협약 구조 정확성 확인
독점권·공동계약·협약 등 계약 관계를 서술할 때:
- 단독 독점인가, 공동 독점(co-exclusive)인가를 원본 출처 기준으로 확인.
- 관계 기업이 여럿인 경우 모두 명시.
- 독점 기간(개월 수·만료일)은 출처 기준 그대로 기재.

### [CHECK 6] 식약처 Section 8 — 기능성 유형 정확성
식약처 행정예고 관련 내용에서:
- 각 고시·예고의 기능성 유형(자외선차단 / 주름개선 / 미백 / 기타)이 정확히 표기되었는가?
- 특정 기업의 개발 사례를 인용할 때, 해당 기업의 기능성 유형이 선케어(자외선차단)인지 다른 기능성인지 확인.
- 다른 기능성(예: 주름개선)을 선케어 맥락에서 혼용하지 않는다.

### [CHECK 7] Section 11 개발 제안 — 개발 제외 제형 최종 확인
Section 11 전체를 다시 읽고:
- **선스틱, 선쿠션, 선밤, 선파우더** 가 단 하나라도 개발 제안에 포함되어 있는가?
- 포함되어 있으면 즉시 삭제하고 허용 제형(선크림·선세럼·선에센스·선스프레이·선밀크·선프라이머)으로 교체.
- 제품명·컨셉명에 위 금지 제형이 암묵적으로 포함되는 경우(예: "고형 선케어", "스틱형 선케어")도 포함 금지.

### [CHECK 8] 허용되지 않는 서술 패턴 점검
